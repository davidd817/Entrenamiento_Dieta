# Train Diet App

A small Streamlit application for creating and organizing personal diet plans.

This project predates [DavidTrain](https://github.com/davidd817/davidtrain) and represents an earlier, simpler iteration of my personal training and nutrition tooling.

## Features

- Create and organize personal diet plans
- Simple Streamlit interface
- Lightweight personal-use workflow

## Tech Stack

- Python
- Streamlit

## Project Status

This is an earlier personal project and is not under active development.

For the more recent training application, see [DavidTrain](https://github.com/davidd817/davidtrain).
